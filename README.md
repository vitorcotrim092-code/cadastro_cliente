# Cadastro de Clientes

Sistema de cadastro de clientes no terminal, feito com Python e SQLite.

## Funcionalidades
- Cadastrar, listar, editar e excluir clientes
- Validação de e-mail duplicado

## Como rodar
1. Instale o Python 3
2. Rode: `python app.py`
git init
git add .
git commit -m "Primeira versão do cadastro de clientes"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/cadastro-clientes.git
git push -u origin main
